# Instructions:
In this assignment, you will work with a computer program to explore and emulate the working of the modern Internet. Begin by familiarizing yourself with the provided [Echo Client and Server Java code](https://docs.oracle.com/javase/tutorial/networking/sockets/readingWriting.html). Download Echo Client and Server CodeLinks to an external site. and ensure it runs correctly on your system. You may use any Java methods to do this (Java version 8 is recommended). Though you are working as a group, each student should individually download the echo client, server code and Java and explore it to see how it works.

Commands:

How to run standard EchoClient and EchoServer files:

```
java EchoServer.java <port>
java EchoClient.java <ip-address> <port>
```

How to run VerboseEchoClient and VerboseEchoServer files:

```
java VerboseEchoServer.java <port>
java VerboseEchoClient.java <ip-address> <port>
```
